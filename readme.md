# Conceptos de Node JS

este proyecto es una practica de  de los primeros conceptos de node js,donde implementamos middlewares, endpoints y fue construido con pnpm como gestor de paquetes.

## Demo del Backend
Podes ver una demo del proyecto aqui [aqui]
(https://cafeteria-sigma-woad.vercel.app/)

## Librerias utilizadas
 -Node Js 24.4 o cualquier version posterior a la 22
-ExpressJs
-Morgan
-Cors

## Instalacion y configuracion del proyecto
1- Clonar el repositorio
`git clone https://github.com/AlmarazAbel/Cafeteria.git`
2-Instalar las dependencias
`pnpm install`
3-Iniciar Aplicacion:
``` bash
#comando de produccion
pnpm start
#comando de desarrollo
pnpm run dev
```
